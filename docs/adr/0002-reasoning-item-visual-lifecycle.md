# 0002: 思考项流式展开后自动归位与单视窗药丸切换

为保持整个轮次在折叠与展开时的整洁度并与原生工具行保持一致，我们决定思考项在流式思考阶段（streaming）保持展开以提供实时透明的打字反馈，在思考完成（complete）后自动平滑收缩归位为紧凑单行。点击展开后采用单视窗模式，在内部通过极简幽灵药丸就地切换译文与原文，异常诊断与重试亦内敛在视窗内呈现，杜绝外层大面积错误报警框。

## 备选方案

- **全程默认折叠**：流式阶段也保持单行收起。该方案完全杜绝了界面抖动，但用户无法实时看到思考进展，丧失了思考反馈的即时感。
- **思考完成后保持展开**：不主动收缩。该方案导致展开轮次后思考文本占据大量垂直高度，削弱了工具流的连贯感。
