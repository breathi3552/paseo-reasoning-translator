# 0002: 思考块流式展开后自动收起与单视窗切换

- **状态**：Accepted

## 背景

如果思考块在生成完成后一直保持展开，长段思考文本会把相邻的工具调用推到屏幕外。如果在流式阶段就默认折叠，用户又无法在等待期间看到模型正在思考的内容。

## 决策

在 `client/timeline.tsx` 中采用以下生命周期与交互规则：

1. **流式自动收起（Streaming Auto-collapse）**：思考块在 `streaming` 阶段保持展开以显示实时原文，在 `complete` 后自动收起为紧凑单行。
2. **单视窗切换（Single-Viewport Toggle）**：点击展开后，在内容区底部通过无底色文字按钮（**显示原文** / **显示译文**、**重新翻译**）就地切换文本，不并排堆叠两份内容。
3. **行内状态提示（Inline Diagnostics）**：错误或超限只在单行尾部显示简短标签，详细说明与 **重试** 按钮在展开后内联呈现。

## 后果

- **优点**：轮次折叠与展开时的页面高度更可控；用户既能看到实时流式输出，又不会被大块错误横幅或双栏译文遮挡工具流。
- **代价**：思考完成瞬间会触发一次自动收起动画，且无法在同一视图下逐句对照原文与译文。

## 备选方案

- **全程默认折叠**：流式阶段也保持单行收起。避免了完成时的高度变化，但用户无法实时查看思考进度。
- **思考完成后保持展开**：不主动收起。长思考文本会长期占据大量垂直空间。
