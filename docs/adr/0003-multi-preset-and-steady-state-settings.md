# 0003: 多连接预设存储与稳态无跳变设置布局

- **状态**：Accepted

## 背景

单槽位连接配置在切换接口格式（Gemini 与 OpenAI 兼容）时会覆盖原有地址与模型，且修改地址或格式时为防止旧密钥误发而清空正在输入的 API Key，导致填写顺序敏感；同时，设置页中按状态动态显隐按钮与提示行会造成界面频繁垂直跳动。

## 决策

1. **纯内联固定表单（无弹窗）**：主卡片顶部在「当前激活预设」同一行放置下拉框与状态合并按钮（未改动时为 `+ 新增预设`、有未保存修改时为 `还原修改`、新建模式时为 `取消新建`），下方固定展示 5 行级联表单（预设名称、API 格式、Base URL、模型 ID、API Key）与底部操作栏（左侧 `测试连接`，右侧 `删除预设` 与 `保存修改 / 保存新预设`）。点击 `+ 新增预设` 后直接将同一组固定表单切为空白新建态，并在「预设名称」标题旁按需显示 `新建预设` / `编辑中` 标签，全程无弹窗且界面零跳变。
2. **稳态表单布局（Steady-state Form Layout）**：整页所有表单行与操作按钮保持固定占位，不可用时使用禁用态（`disabled`）而非隐藏或移除；「目标语言」改为失焦/回车自动保存，消除动态操作行。
3. **强校验与密钥保护**：保存预设要求名称、格式、Base URL、模型 ID 与可用 API Key 齐全；切换格式或修改地址时绝不清空用户当前正在输入的 API Key。

## 备选方案

- **主卡固定编辑 + 仅新增弹框**：新增预设时弹出独立 Modal，但引入了额外弹窗层级。
- **主卡极简、新建与编辑全部弹窗**：主页面最紧凑，但查看或微调当前预设的 URL 与模型 ID 需要额外点击进入弹窗。
