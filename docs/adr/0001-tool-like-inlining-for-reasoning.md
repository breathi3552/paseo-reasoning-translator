# 0001: 采用单行拟态呈现思考项而非修改宿主聚合管线

由于 Paseo 宿主将所有插件时间线项强制投影为 `plugin` 且其工具聚合机制（`isGroupableToolCall`）目前仅放行内置 `thought` 与 `tool_call`，导致第三方插件拦截思考后会打断宿主的连续工具聚合。我们决定在插件客户端采用与原生工具（如 `Read`）完全对齐的**单行拟态（Tool-like Inlining）**，默认折叠为紧凑单行并在点击时内联展开详情，从而在保持纯插件架构通用兼容性的同时，在视觉与交互心智上彻底消除截断感。

## 备选方案

- **修改 Paseo 宿主客户端代码**：在宿主 `grouping.ts` 中针对本插件放行。该方案虽能在数据层被宿主聚合组直接吸收，但强制依赖定制版 Paseo 客户端，丧失了作为独立插件向普通用户分发的通用性。
