# 0001: 采用单行拟态呈现思考块而非修改宿主分组逻辑

- **状态**：Accepted

## 背景

Paseo 宿主将所有插件时间线项强制归类为 `plugin`。宿主的连续工具分组逻辑（`isGroupableToolCall`）目前只放行内置 `thought` 与 `tool_call`，导致第三方插件接管思考渲染后，无法在数据层并入宿主的工具聚合组（Tool Group）。

## 决策

在插件客户端（`client/timeline.tsx`）采用与原生工具调用（如 `Read`）一致的**单行拟态（Tool-like Inlining）**。思考块在完成后默认折叠为紧凑单行，点击后内联展开详情。

## 后果

- **优点**：插件无需修改 Paseo 客户端源码即可安装运行，且思考块在视觉高度和对齐方式上与相邻工具调用保持一致。
- **代价**：在数据层它仍会打断宿主的连续工具聚合，无法被合并进“读取了 N 个文件”这类单条聚合摘要中。

## 备选方案

- **修改 Paseo 宿主客户端代码**：在宿主 `grouping.ts` 中针对本插件放行。该方案能让思考块并入宿主工具聚合组，但强制依赖定制版 Paseo 客户端，无法作为独立插件分发。
