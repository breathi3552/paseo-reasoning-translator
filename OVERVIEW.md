Paseo think what translates visible agent reasoning directly through Google Gemini’s native generateContent API or an OpenAI-compatible Chat Completions endpoint.

During generation, the timeline shows paced original text. Manual mode is the default: click Translate on a completed block to submit only that block. Opening a session or loading history does not queue translations. Optional automatic mode submits completed reasoning and loaded history. Results appear in place, with original/translation switching and folding. A failed progress query resumes the same job rather than sending another model request.

Requires Paseo daemon and client 0.15.0 or later. Translation is disabled by default. Open settings from the sidebar or Command Center, save a connection, then enable translation. The default format is Gemini, Base URL https://generativelanguage.googleapis.com/v1beta, model gemini-3.5-flash-lite. For OpenAI-compatible services, enter your Base URL and exact model ID. SenseNova’s compatible Base URL can be https://api.sensenova.cn/compatible-mode/v2; the model must come from your account.

Settings and limits:
- One current connection: format, Base URL, model and API key. Saving does not send a test request. Changing endpoint or format requires a newly entered key or explicit deletion; changing only the model can retain the saved key.
- Keys live in the daemon’s unencrypted file at PASEO_HOME/plugin-data/paseo-think-what/connection.json, or ~/.paseo/plugin-data/paseo-think-what/connection.json when PASEO_HOME is unset. Directory/file permissions are restricted where supported. This is not an OS credential vault. Metadata never returns the key, and successful saves clear its input.
- Target language is configurable; Simplified Chinese is the default. Each source block supports up to 200,000 characters. Long text is split into 12,000-character paragraph chunks and translated in order.
- HTTP concurrency is 1, with up to 64 waiting jobs and 128 cached results. Results expire after 30 minutes. Each request, including response reading, has a 120-second deadline and a 2,000,000-byte response limit. Failures, refusals and truncation are visible and never trigger automatic resends.
- Changing connection, model, key or settings cancels old work and revokes old results. Manual clicks are scoped to host, agent, exact source and configuration revisions. Clients refresh key-free metadata about every 5 seconds; the daemon also rejects stale submissions.

The plugin sends only visible reasoning and the target language to your chosen API. It creates no Paseo agents or workspaces and uses no tools or MCP servers. Translations consume your API account’s quota, and the provider may retain request text under its policies. Plugin result caches are in memory. Provider response bodies, source text and credentials are not written to plugin logs. HTTPS is required except for loopback HTTP endpoints.
