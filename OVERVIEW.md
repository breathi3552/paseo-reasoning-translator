Paseo Reasoning Translator translates visible agent reasoning directly through Google Gemini’s native generateContent API or an OpenAI-compatible Chat Completions endpoint.

During generation, the timeline shows paced original text. Manual mode is the default: click Translate on a completed thinking block to submit only that block. Opening a session or loading history does not queue translations. Optional automatic mode submits completed reasoning and loaded history. Results appear in place, with switching between the original text and its translation, plus folding. If a progress query fails, clicking Resume query recovers the same job rather than sending another model request.

The plugin requires Paseo daemon and client 0.15.0 or later. Translation is disabled by default. Open settings from the sidebar or Command Center, click + Add preset (which defaults to Gemini, Base URL https://generativelanguage.googleapis.com/v1beta, and model gemini-3.5-flash-lite), save a connection, then enable translation. For OpenAI-compatible services, enter your Base URL and exact model ID. SenseNova’s compatible Base URL is https://api.sensenova.cn/compatible-mode/v2; the model ID must come from your account.

Settings and limits:
- Multi-preset connections: each preset stores its own name, format, Base URL, model, and API key, and switching presets never overwrites others (legacy single-connection files are read seamlessly). Saving sends no test request; use Test to verify an endpoint. Changing format or Base URL requires re-entering an API key before saving or testing, without clearing what you are typing mid-edit.
- Keys live in the daemon’s unencrypted file at PASEO_HOME/plugin-data/paseo-reasoning-translator/connection.json, or ~/.paseo/plugin-data/paseo-reasoning-translator/connection.json when PASEO_HOME is unset. Directory and file permissions are restricted where supported. This file is not an OS credential vault. Metadata never returns the key, and successful saves clear the input field.
- Target language is configurable, with Simplified Chinese as the default. Each source block supports up to 200,000 characters. Long text is split into 12,000-character paragraph chunks and translated in order.
- HTTP concurrency is 1, with up to 64 waiting jobs and 128 cached results. Results expire after 30 minutes. Each request, including response reading, has a 120-second deadline and a 2,000,000-byte response limit. The plugin displays failures, refusals, and truncated responses inline and never resends a failed request automatically.
- Changing the connection, model, key, or settings cancels old work and revokes old results. Manual clicks are scoped to host, agent, exact source text, settingsRevision, and connectionRevision. Clients refresh key-free metadata every 5 seconds, and the daemon rejects stale submissions.

The plugin sends only visible reasoning and the target language to your chosen API. It creates no Paseo agents or workspaces and uses no tools or MCP servers. Translations consume your API account’s quota, and the provider may retain request text under its policies. Plugin result caches live in memory. Provider response bodies, source text, and credentials are never written to plugin logs. HTTPS is required except for loopback HTTP endpoints.
